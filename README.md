## AI policy

As a practicing Muslim, amongst many attributes as a believer in the Creator, I greatly value accountability, trasparancy and honesty. Therefore, I am of a view that AI should be responsibly used as a tool. As a result, I'm totally against the usage of vibe coding during production for numerous reasons. For demos and MVPS, I would not mind if vibe coding were used to showcase the potential of the project and for the sake of exploring options, but it must be clearly communicated to the client for the sake of transparancy, and a capable team must be prepared to tackle the tasks at hand.

To clarify, I view "vibe coding" as the following:
> Some commentators argue that a key to the definition is a lack of knowledge about the code, and that thorough review and testing is incompatible with the definition of vibe coding. Programmer Simon Willison said: "**If an LLM wrote every line of your code, but you've reviewed, tested, and understood it all, that's not vibe coding in my book—that's using an LLM as a typing assistant.**" <https://en.wikipedia.org/wiki/Vibe_coding#cite_note-Edwards-2025-1>

With this in mind, If a client rightfully demands that AI should not be used, then it should be wholeheartedly honored. Deception are totally against my religious moral code of ethics.
